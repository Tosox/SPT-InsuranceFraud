## 📜 Description

Ditch it anywhere, Prapor knows where to look! **Insurance Fraud** for *Single Player Tarkov* makes sure that every insured item you drop during a raid is returned to you 100% of the time, regardless of the trader's insurance return rate.

Insured gear that is still on your body when you die is handled by the regular insurance rolls. Only insured items that were no longer on you when the raid ended are guaranteed to come back, including their attachments.

## 📁 Installation

* Download the latest release
* Copy the `SPT` folder into your SPT installation
* Start the game
